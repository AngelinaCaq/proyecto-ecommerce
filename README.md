# 🛒 Ecommerce con Nuxt

## 📌 Descripción
Aplicación web desarrollada con Nuxt que permite listar productos/personajes desde una API y ver su detalle individual.

---

## 🚀 Tecnologías
- Nuxt (Vue 3)
- JavaScript
- CSS
- API REST

---

## ⚙️ Funcionalidades
- Listado de productos/personajes  
- Vista de detalle por ID  
- Navegación entre páginas  
- Estado global con composables  
- Consumo de API  

---

## ▶️ Instalación
```bash
git clone https://github.com/tu-usuario/ecommerce-nuxt.git
cd ecommerce-nuxt
npm install
npm run dev
